# Diseño de capítulos y pliegos

## Objetivo y contenido

Definir un objetivo observable por capítulo y registrar sus páginas fuente. Combinar explicación, ejemplo aplicado, interacción pertinente y actividad con retroalimentación. Ajustar extensión a la legibilidad; no omitir contenido crítico para encajar en una página.

En la plantilla pop-up, usar la página izquierda para contexto, explicación y una pregunta de predicción. Reservar la derecha para la escena, sus controles, explicación de resultados y desafío. La API de construcción está en `arquitectura.md`.

## Interacciones para capacitación

| Contenido | Interacción | Verificación |
|---|---|---|
| Proceso secuencial | Un objeto atraviesa estaciones y cambia de estado | Avance manual, pausa, reinicio y explicación de cada etapa |
| Decisión | Elegir una ruta y observar consecuencias | Todas las ramas y retornos sustentados por la fuente |
| Responsabilidades | Carriles por área con transferencias visibles | Responsables y condiciones fieles al PDF |
| Transformación | Comparar estados antes y después | Variables y simplificaciones explícitas |
| Relación entre variables | Controles que modifican un modelo | Cálculos contrastados con valores conocidos |
| Comparación conceptual | Tabla o esquema con selección | Diferencias explicadas sin forzar movimiento |

Preferir escenas 3D solo cuando ayuden a comprender. Usar los contratos de `animaciones.md` y `animaciones-3d.md`; mantener esquema 2D y texto equivalente.

## Actividades

Pedir aplicar lo explicado: elegir una acción ante un caso, ordenar etapas, detectar un control faltante o justificar una decisión. Usar distractores plausibles y explicar errores. Permitir reintentos; evitar desafíos basados únicamente en memoria, clics al azar o límites de tiempo innecesarios.

Identificar como ficticios los casos añadidos. No convertir ejemplos, controles sugeridos o simplificaciones en obligaciones de la fuente.

## Presentación

Usar títulos breves, HTML legible, rótulos cortos y controles con nombres claros. Explicar cada cambio visual en texto. Reservar el color para diferencias relevantes sin depender solo de él. Evitar rótulos superpuestos y elementos que crucen el lomo. Verificar adaptación móvil, teclado, contraste y reducción de movimiento.
